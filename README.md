# HASHASHIN

A Python-based multi-tool environment for Termux.

## Features
- Cybersecurity Utilities
- Network Tools
- System Information
- Basic File Scanner
- Password Generator
- Hash Generator

## Requirements
- Android
- Termux
- Python 3

## Run
python main.py

## Disclaimer
Educational and authorized use only.
The built-in file scanner is heuristic and is not a replacement for a full antivirus.
